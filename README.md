# ThruHealth

*À travers ma santé, se connaître au-delà du miroir.*

ThruHealth est une expérience web en 3D, guidée par Ama, qui aide à comprendre des pathologies notemment cancérigènes. On commence avec le sein, les masses et les signes qui doivent pousser à consulter. Tout se passe dans le navigateur, sans installation ni compte, et rien n'est enregistré.

Mini-projet de A. Marie-Adelphe A.

## Avertissement

ThruHealth est un petit outil 3D de sensibilisation. Il ne remplace pas l'avis d'un médecin ou d'une sage-femme. 
Les ressources de la boîte cadeau appartiennent à leurs éditeurs respectifs.
